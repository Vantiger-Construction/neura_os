Care Mode 2.0 – Trusted Contacts + Crisis Playbooks
===================================================

This pack fills in the missing pieces for Care Mode 2.0:

- Trusted contacts storage and UI
- Crisis playbooks screen
- A Care Mode home screen that ties these together
- Gentle, safety-first language and self-healing storage

Where it plugs into your OS shell
---------------------------------

Your OsShellHomeScreen already imports:

    import '../../care/screens/care_mode_home_screen.dart';

and uses it in the "Care Wing" room. Dropping these files in will satisfy
that import and give the room a real, meaningful screen.


What Care Mode now does
-----------------------

- Shows an emergency disclaimer card at the top, reminding users to contact
  local emergency services or crisis hotlines when needed.
- Lets users manage a list of trusted contacts:
    * Name, relationship, phone, notes
    * Mark as "emergency" and/or "professional"
    * Stored locally via SharedPreferences
    * Self-heal: if stored JSON is corrupted, it is cleared safely and rebuilt.
- Shows emergency contacts as chips under the Trusted Contacts tile.
- Provides a set of built-in crisis playbooks for situations like:
    * Feeling Overwhelmed
    * Anxiety Spike
    * Feeling Very Unsafe or In Danger
  Each playbook offers gentle, practical steps and ends with a safety disclaimer.
- Care Mode Home screen explains that Neura is supportive but not a replacement
  for professional care or emergency services.


How to wire from navigation
---------------------------

You can also link to Care Mode directly from your main dashboard or menus:

    import 'package:your_app/care/screens/care_mode_home_screen.dart';

    ListTile(
      leading: const Icon(Icons.favorite),
      title: const Text('Care Mode'),
      subtitle: const Text('Trusted contacts and crisis playbooks.'),
      onTap: () {
        Navigator.of(context).push(
          MaterialPageRoute(builder: (_) => const CareModeHomeScreen()),
        );
      },
    );

The OsShellHomeScreen already covers this as the "Care Wing" room.


Dependencies
------------

This pack uses:
- shared_preferences (already required by other parts like persona and mood)

Make sure your pubspec.yaml includes:

    dependencies:
      shared_preferences: ^2.2.0   # or whatever version you're already using

Then run:

    flutter pub get


Safety reminder
---------------

This Care Mode implementation is intentionally cautious:

- No instructions for self-harm or violence.
- Encourages contacting trusted people, professionals, and emergency services.
- Clearly states that Neura is not a doctor, therapist, or emergency responder.

You can localize crisis hotline mentions later, but the logic is safe to ship
as a baseline in most regions.
