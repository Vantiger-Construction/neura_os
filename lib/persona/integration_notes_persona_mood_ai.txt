Neura Persona + Mood Integration – Usage Notes
=============================================

Drop these into your app:
  - lib/persona/models/neura_response_style.dart
  - lib/persona/services/neura_behavior_adapter.dart
  - lib/persona/services/neura_prompt_builder.dart

These expect you already added:
  - PersonaProfile + NeuraPersonaService (from previous pack)
  - MoodStateService + MoodThemeService (from previous pack)


Typical usage from your Neura AI engine
--------------------------------------

Example: inside your chat / completion code before calling the LLM:

  import 'package:your_app/persona/services/neura_prompt_builder.dart';
  import 'package:your_app/persona/models/neura_response_style.dart';

  Future<void> sendNeuraMessage(String userMessage, {String module = 'journal'}) async {
    final promptBuilder = NeuraPromptBuilder.instance;

    // 1) Figure out style from persona + mood:
    final NeuraResponseStyle style =
        await promptBuilder.resolveStyle(module: module);

    // 2) Get system message snippet:
    final systemMessage = style.systemPromptSnippet;

    // 3) Use these in your LLM client (pseudo-code):
    // final response = await myLlmClient.sendChat(
    //   system: systemMessage,
    //   user: userMessage,
    //   metadata: {
    //     'tone': style.toneLabel,
    //     'difficulty': style.difficulty,
    //     'jokeFrequency': style.jokeFrequency,
    //     'depthLevel': style.depthLevel,
    //   },
    // );

    // 4) Use style.difficulty for UI / task difficulty:
    //   - gentle: smaller goals, softer prompts
    //   - normal: default goals
    //   - challenge: slightly harder goals, more ambitious framing
  }


Wire-in spots
-------------

- Before ANY Neura response (journal, rituals, therapist mode, daily check-in),
  call NeuraPromptBuilder.instance.buildSystemMessage(module: '<module>')
  and feed that into your AI system prompt.

- If you use different Neura "modes", pass them as module hints:
    - 'journal'
    - 'rituals'
    - 'care_mode'
    - 'dream_show'
    - 'weekly_snapshot'
    - 'kids_mode'
    - etc.

This is what makes the persona sliders + mood actually change how Neura talks,
not just sit in storage.

You can also use NeuraResponseStyle to pick different animations, voice tone,
or avatar states in your UI logic.
