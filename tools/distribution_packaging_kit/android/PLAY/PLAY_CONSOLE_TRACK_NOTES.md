# Play Console Track Notes (Neura Public v1)

## Internal testing
Use for:
- smoke tests on real devices
- verifying signing, install, permissions
- testing your store listing screenshots quickly

Checklist:
- Upload AAB
- Add 10–20 tester emails
- Create release notes (short, calm)
- Verify install + first-launch + voice toggle + delete data

## Closed testing
Use for:
- wider feedback (50–500)
- stability on varied devices
- watching for "talks too much" red flags

Checklist:
- Keep release notes minimal
- Do NOT add features from feedback during closed test
- Fix only crashes/blockers

## Production
Use staged rollout:
- 10% for 48–72 hours
- 50% for another 72 hours
- 100% only after stability confirmed

## Review risk reducers
- Avoid medical / therapeutic claims in listing
- Make privacy + delete-data obvious
- Keep permissions minimal (only what you use)
