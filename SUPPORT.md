# Getting help with Neura

- **App or build problem:** open a
  [bug report](https://github.com/Vantiger-Construction/neura_os/issues/new/choose).
  Include version/commit, OS, reproduction steps and expected result. For startup
  failures, include the exact package identity and a short redacted crash excerpt
  if available.
- **Usage question or idea:** use
  [Discussions](https://github.com/Vantiger-Construction/neura_os/discussions),
  or the feature-request form for a concrete proposal.
- **Suspected security or privacy vulnerability:** follow
  [SECURITY.md](SECURITY.md) and use private reporting.

Public issues and discussions are visible to others. Use sample information and
review attachments. Do not post journals, recordings, credentials, private
account details or complete app-data folders. Avoid reinstalling or wiping data
as a generic troubleshooting step.

See the [developer guide](docs/DeveloperGuide.md) for source setup. Build success
and physical-device acceptance are separate. Identify the exact source or release
when asking for help. No response-time guarantee is implied.
